## Three tension points recorded as needing a decision (still open)

1. **Customer path vs. shortcuts** — Avi Bar fears the agent shortens the in-store/site route and hurts exposure and impulse buying; Michal says customers want shortcuts and the impulse "loading up" happens at the end anyway.
2. **Restaurant info** — Avi Yoktan sees value for customers and employees; Michal thinks it is off-goal for now.
3. **Move to WhatsApp** — Michal fears attrition versus the value the website generates; others see WhatsApp as the primary channel.

Footnote in the doc: several "in the bot" capabilities exist at a basic level but had not been through heavy user testing; logic and edge cases to be tightened before launch.

## How to use this now

- This is the requirements ledger IKEA's stakeholders recognise. The retainer/upsell split (`2026-07-29-retainer-work-plan-deck.md`) should cite these numbers so every "new" request is visibly old, sourced, and either in the retainer or priced.
- #11 (tone & style) is the one cheap, unticked item that a named IKEA VP asked for and whose input we already hold (the tone-of-voice PDF in Drive `Context - Agent`).
